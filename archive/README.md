# AI-WRITABLE: 归档区（历史项目 / 旧文档 / 已完成任务）

## 归档规则

- 只进不出：归档内容默认不再修改；确需修改走 README 的回退 / 提交流程。
- 每个归档项目一个子目录，命名：`YYYY-MM_<项目名>/`，内含说明文件与相关材料清单。
- 零散旧文档直接放本目录，文件名前缀日期：`YYYY-MM-DD_<文档名>.md`。
- 归档动作完成后，必须在下方索引表登记一行。
